# TextPolish

Build:

```powershell
pip install -r requirements.txt
.\build.ps1
```

Run:

```text
release\TextPolish.exe
```

Use:

- `Ctrl+Shift+Q` normalizes the selection
- `Ctrl+Alt+Shift+Q` opens preview first
- The app stays in the tray
- Right-click the tray icon for settings

Edit `rules.json` to change replacements.
